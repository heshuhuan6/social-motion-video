# 导演与迭代

## 从资料长出风格

提取身份中最具体的矛盾、持续发布的行动、头像形状色彩、关注者能获得的内容。转为镜头里的物体与关系：实验→聚合拆解，实测→扫描标记，陪伴→相互回应的主体。概念画面不能包装成真实作品截图。

| 已实践方向 | 意图 | 视觉方法 | 节奏经验 |
|---|---|---|---|
| 暖色手记 | 真诚、生活感 | 纸张、照片卡、手绘线、低饱和 | 温和入场，充分阅读 |
| 黑金预告 | 更酷、有质感 | 明暗反转、金属物件、头像透视、粗体字 | 约 120 BPM，避免仅背景旋转 |
| 海报卡点 | 紧凑、直接 | 头像切片、错位色块、短缩放、定格 | 150 BPM / 30fps，每拍 12 帧 |
| 三维微缩叙事 | 新创意、有故事 | 有内容含义的道具、绕行、逐步组装 | 同一物件跨镜承接，情绪段减法 |
| 强冲击动作 | 前三秒抓人 | 超近景→穿入→爆开，俯拍/斜侧切换，硬光大字 | 180 BPM / 30fps，每拍 10 帧 |

这些是创作方向，不是固定模板。配色、材质应能解释与账号内容和头像的关系。

## 将反馈翻译成动作

**更酷**：增加轮廓对比、文字尺度差、空间层次；用一两个贯穿母题建立辨识度。

**快节奏卡点**：缩短句子、重排镜头长度、音画共用 beat map。切镜、文字撞入、物体落地同拍；次要动作可半拍。不要只加速旧片。

**做一版新的**：换视觉命题、叙事载体或镜头语法。同一资料可从手记变成微缩工作台，再变成动作片。事实不变，表达重新设计。

**还是温柔，前三秒抓人**：第一帧主体要大；第 1 秒完成动作，第 2 秒改变尺度或观察方向，第 3 秒给回应。长缓动改短冲击与落稳。密集段之后留声音减法，让下一次重拍有差异。少用连续满屏闪白。

**加有力量的中文配音**：短句、重音、句尾收住，按已有剪辑分段生成。力量来自表现、停顿、混音；先试普通句和最长句，避免只提高语速。

## 20 秒分镜骨架

| 秒 | 任务 | 主动作建议 |
|---|---|---|
| 0–1 | 身份钩子 | 超近景下压 / 旋开 |
| 1–2 | 欲望或问题 | 穿入 / 尺度突变 |
| 2–3 | 行动态度 | 组装 / 爆开 / 明确结果 |
| 3–5 | 名字与定位 | 全景建立空间，再换方向 |
| 5–11 | 2–3 个内容方向 | 每镜不同动词与构图 |
| 11–15 | 真实动机或实例 | 维持视觉语言，改变声音密度 |
| 15–17 | 回顾 | 信息逐拍高亮 |
| 17–20 | 完整账号名片 | 稳定名字、账号、定位 |

没有真实实例时用具体内容方向，资料少就缩短片长。先做开头、中段、结尾风格帧与前三秒动态预览，确认视觉真的改变，再全片渲染。
