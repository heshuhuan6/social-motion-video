# 配音与混音

## 服务

沿用用户指定供应商和预算，核对当前地区、登录、模型额度、音色、下载能力。网页会员与 API 额度分开看；浏览器试用可完成时无须开 API。

本案例曾以火山引擎 Doubao TTS 1.0“广告解说”、语速 +20，完成 11 句共 85 字符。这是成功案例参数，执行时重新核实当前入口、名称和免费额度。Google 路线检查实际语音生成入口与账户能力。

口吻可描述为“普通话，中低音，有力量、干脆、自信；重音明确、咬字清晰、句尾收住；开场逐级增强，AI 读 A I”。音色按账号选择，不固定男声。

每镜独立生成，序号命名，记录原文、音色、参数与下载状态。重试前查历史和本地文件，避免重复消耗。单段失败一到两次后检查原因，保留已完成段落。登录由用户完成，额度不足时不自行付费。浏览器需要短时前台协助时只请求必要时段，完成后告知。

## 对齐

复制 assets/voice-plan.example.json 到项目，填文字、文件和窗口。路径相对配置文件。video 是认可画面；music 是独立配乐，勿填已有口播的音轨。start/end 是秒，以镜头结束为硬边界。

```bash
python3 /path/to/social-motion-video/scripts/mix-voice.py work/voice/plan.json --out-dir out/voice-v2
```

脚本校验所有窗口与文件，然后去首尾静音→适度提速→EQ/轻压缩/响度统一→延时排布→配乐侧链压低→两遍 loudnorm→复制视频流、编码 AAC。

默认 maxSpeed=1.15 是实践听感阈值；超过时改短文案或重新生成，允许重剪时再调整镜头。不要强截尾音。实际处理后长度再次核窗口。SRT 使用实际开始与长度及口播原稿。

目标约 -14 LUFS，编码前留 -1.8 dBTP 余量，以 AAC 实测为准。

## 原创配乐

```bash
node /path/to/social-motion-video/scripts/make-beat.mjs --out work/music.wav --bpm 180 --fps 30 --duration 20 --cuts 30,60,90,150,210,270,330,390,450,510 --break 12.66,13
```

仅 Node 内置库，程序合成鼓组、低音、短和弦、拨弦、滑音，无网络。输出原始配乐，需混音与响度处理。改 BPM 同时改镜头与动作；声音减法与重拍返回形成差异。鼓起音与低频能量峰区分测量，后者通常略晚。

## 听审

听开场、最长句、名字/账号、字母词、末句及配乐压低恢复。听不清先调整配乐电平与遮蔽频段。自动转录辅助核对漏句与顺序，名字同音字回到音频和原稿确认。没有回放能力时记录时间/电平检查已完成、听审待完成。
