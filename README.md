# Social Motion Video · 社交账号动态图形短片

A portable AI skill for making account-introduction motion graphics with code, beat-synced editing, Chinese voiceover, and local media checks.

把“我是谁、发什么、为什么值得关注”做成有辨识度的短片。适用于 Codex、Claude Code 和能够读取文件、执行本地命令的其他编程 AI。

## 能做什么

- **五种视觉方向**：暖色手记、黑金预告、海报卡点、三维微缩叙事、强冲击动作。
- **按反馈迭代**：把“更酷”“更快”“开头三秒更抓人”转成具体的镜头、尺度、节奏和声音变化。
- **代码生成画面**：Remotion、HTML/CSS/SVG、Three.js / React Three Fiber，也可按内容选 Canvas 等方案。
- **中文配音卡点**：按镜头分句、裁首尾静音、适度提速、自动压低配乐、响度处理与 SRT 导出。
- **验收交付**：完整解码、规格核对、疑似空白帧检测、编码后响度测量和封面抽帧。

本项目是一套制作方法与辅助工具。画面由 AI 根据当前账号资料编写；随包的动作组件用于复用常见效果。

也可放到项目的 `.claude/skills/social-motion-video/`。在请求中写“使用 social-motion-video”。已有同名目录时先检查并保留自己的改动。

### 其他 AI

下载仓库，让 AI 先读取 [SKILL.md](SKILL.md)，再按需读取其中的参考资料。无需专有连接器；需要编辑文件、执行命令，浏览器与 TTS 账户按具体任务接入。

## 一句话开始

> 使用 social-motion-video，为我的账号做一条 20 秒竖屏介绍片。主页是……，头像在 assets/avatar.jpg。只使用真实信息，免费方案优先，前三秒有冲击；末屏保留名字、账号和定位。输出视频、封面、源码和说明。

继续迭代：

> 这版还是温柔。请保留真实内容，重新设计前三秒：超近景、穿入、爆开，镜头方向变化更大胆，音画卡点更紧。保留旧版本。

给认可的画面加口播：

> 使用我的火山引擎免费额度生成中文配音，短句有力量，按已有镜头窗口对齐，配乐在人声出现时压低，保留画面。

## 工具用法

以下命令在仓库根目录执行，实际素材与输出可位于自己的项目。

### 生成原创节拍

```bash
node scripts/make-beat.mjs --out work/music.wav --duration 20 --bpm 180 --fps 30 --cuts 30,60,90,150,210,270,330,390,450,510 --break 12.66,13
```

输出 WAV 和 `.beats.json`。这是一条原始配乐，交付前仍需混音和响度处理。

### 配音对齐与混音

复制 [配置示例](assets/voice-plan.example.json)，填入现有视频、独立配乐、每句音频、真实文本与时间窗口。相对路径基于配置文件所在目录。

```bash
python3 scripts/mix-voice.py /path/to/plan.json --out-dir /path/to/out/voice-v2
```

输出目录须为空。输出 `intro-voice.mp4`、`voice.wav`、`mix-master.wav`、`voice.srt` 和 `sync-check.json`。保留原视频流，生成 AAC；超出窗口或提速上限时停止，留给改文案或重新生成。服务端语音生成由 AI 在用户指定工具中另行完成。

### 验片与封面

```bash
python3 scripts/check-video.py /path/to/intro.mp4 --width 1080 --height 1920 --fps 30 --duration 20 --cover-time 18.6 --out-dir /path/to/qa
```

输出规格、逐帧统计、响度报告和 `cover.jpg`。非零退出表示失败或有待复核项。文字几何、画面审美和实际听感另按[验收流程](references/verification.md)检查。

## 验证

```bash
python3 -m unittest discover -s tests -v
```

测试使用临时目录与程序生成的素材，不需要账户或付费 API。覆盖节拍时间、非法输入、覆盖保护、空白帧识别和短片混音；完整测试需 Node.js、FFmpeg、ffprobe。

发布前还在 20 秒、1080×1920、30fps 的实际工程中验证过 11 句配音：全部落在对应镜头内，画面流 hash 一致，最终约 -14.12 LUFS；600 帧完整解码检查通过。
